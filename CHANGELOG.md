# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-03

- Initial ActiveTime multi-loader release
- Automatic simulation freeze when no players are online
- Automatic simulation resume when a player joins
- Fabric support (`activetime-fabric-1.0.0.jar`)
- Forge support (`activetime-forge-1.0.0.jar`)
- Paper support (`activetime-paper-1.0.0.jar`)
- Native Minecraft simulation tick control (Minecraft 1.20.3+)
- Admin commands (`/activetime [status|freeze|unfreeze|reload]`)
- Configuration support with customizable notifications
- Shutdown safety protection
